# KČT — 3 vizuální styly (skiny) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **⚠️ VERZOVÁNÍ:** Uživatelské globální pravidlo zakazuje jakýkoli `git commit`, `git push`, práci s větvemi. **Nikdy necommitovat ani nenavrhovat commit.** Verzování si dělá uživatel sám. Tam, kde běžný plán říká „commit", tento plán říká „build + vizuální ověření".

> **⚠️ TESTOVÁNÍ:** Projekt nemá CSS unit-test harness. Ověření = `npm run build` proběhne bez chyby + vizuální porovnání v prohlížeči proti referenčním designům `KCT Homepage 1a/1b/1c`. Kde je to možné, ověřuje se i přítomnost tříd/souborů g:grepem.

**Goal:** Umožnit v Customizeru vybrat 1 ze 3 vizuálních stylů (Obrazový / Časopisový / Kartový), který přeskinuje celý web; každý skin = jeden self-contained CSS soubor (core + tokeny + overrides), na stránce se načte přesně jeden.

**Architecture:** Sdílený skin-agnostický SCSS `core/` (čte `var(--token)`) se `@import`uje do tří skin entry (`skins/photo|magazine|cards.scss`); webpack zbuildí `photo.css`/`magazine.css`/`cards.css`. `functions.php` enqueue jen zvolený skin dle `get_theme_mod('kct_skin')` + `body_class skin-<slug>`. Editovatelné tokeny (primary_color aj.) jde přepsat přes Customizer, doručeno linkovaným `dynamic-styles.php` (ne inline).

**Tech Stack:** WordPress (theme `kct` uvnitř pluginu), `@wordpress/scripts` (webpack), SCSS s `node-sass-glob-importer`, CSS custom properties, WP Customizer.

**Kořen pluginu (všechny cesty relativní k němu):** `wp-content/plugins/kct/`
**Build:** `cd wp-content/plugins/kct && npm run build`

function kct_scripts() {
	$allowed = array( 'photo', 'magazine', 'cards' );

	if ( ! in_array( $skin, $allowed, true ) ) { $skin = 'photo'; }
